## Why the sources matter more than the tree

The campaign's cost model is
`GM = (Π REF_i / cost_i)^(1/3)`, so a **1 % cut in any one leg is worth
+0.1105 GM** at our current 33.17, and for the inverse-square-root leg
`cost = Q × toffoli_equivalent` with

```
toffoli_equivalent = toffoli_count + T/4 + n_rot·(0.56·log2(1/eps)+5.3)/4
```

so **one Toffoli removed from a 37 q circuit is worth ≈ +0.0067 GM**, and the
33 rotations alone contribute ≈ 239 of the 1,646.69 toffoli-equivalents
(14.5 %) — i.e. the rotation fit margin (`eps`) is itself a lever.

The ISR bundle contains the machinery that moves all of these knobs:

```
repo/experiments/isr/iterations/758_isr_leader_public/public_generator/invsqrt/
  tools/invsqrt_fc_narrow.py     <- narrow in-place adders: trade carry wires
                                    for ANDs via a checkpoint schedule at C
                                    clean wires  (THE H30 MECHANISM)
  tools/invsqrt_fc_lanes.py      <- lane search
  tools/invsqrt_fc_s18cubrank.py <- cubic-rank compression
  tools/r54_inv_tail_sat.py      <- SAT-based tail optimisation
  tools/lut_synth_fast.py        <- angle/LUT synthesis
  tools/lut_synth_smooth.py
  tools/invsqrt_fk_router.py     <- wire router
  tools/invsqrt_fk_epkit.py / _epN.py
  tools/invsqrt_fw_m7mux.py / _fw_fcpol.py
  cfg/{cfg_M,cfg_b312g,cfg_dq18c}.json, prog/, data/r59b0/
```

`invsqrt_fc_narrow.py` is precisely the *algorithmic divider rewrite* that the
H24 lane concluded was the only route to fewer wires: "carries follow the
checkpoint schedule at C clean wires — blocks of carries; interior carries are
removed free, top-down; each block keeps its top carry; after the top, the
kept carries are ghosted top-down (X-measured) and each is repaired under its
ghost bit".  It narrows **in-place adders**, i.e. it attacks the same
7-wire reverse-carry storage that our own `work/tools/h24_pipeline_carry.py`
replaced with a pipelined carry — but with a provable AND-count schedule
(`sched(L, C)`) instead of a hand-written rewrite.

The 772 lane is the "dial" rewrite: a traced patch recipe
(`dial_recipe.json`: op-level old→new patches plus an LP fit of 33 rotation
turn-units with 4,182 constraints, lp_margin 38,906,787.97, 0 phase failures)
that turned the previous held ISR (63,052.041889631386) into
62,993.51131455168 — a gain of **58.53 cost units** (≈1.5 Toffoli-equivalents).
