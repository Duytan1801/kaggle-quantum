# Quantum 2026 v154: chemistry generator source (private)

Rebuilds the v154 chemistry member(s) from this archive alone: candidate `chemistry/766_chem_757_exact/release_757x`.
Run `python -B build.py OUTDIR`; every file in `SHA256SUMS` must match. Needs Python 3.13 and numpy.

## Contents

- `repo/experiments/chemistry/iterations/766_chem_757_exact/package/`: the coordinator's handoff package (q2026-handoff-v1); its `RECIPE.json` lists every build file and repository input with its SHA-256, from a traced build.
- `repo/...`: every repository file the traced build read (same paths as in the repository).
- `build.py` + `BUILD.json`: the generic entry point; `MANIFEST.json`: every archived file and where it came from.
